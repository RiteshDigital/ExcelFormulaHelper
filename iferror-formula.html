IFERROR Formula in Excel

Replace Excel formula errors with a useful result.

What is IFERROR?

IFERROR checks whether a formula produces an error and returns an alternative result when it does.

Example

=IFERROR(XLOOKUP(E2,A2:A100,B2:B100),"Not Found")

Instead of displaying an error, the formula displays Not Found.

Tip: Use IFERROR carefully so genuine data problems are not hidden.
