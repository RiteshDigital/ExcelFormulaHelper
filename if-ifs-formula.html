IF and IFS Formulas in Excel

Create conditional results in Excel based on one or more tests.

IF formula

IF returns one result when a condition is TRUE and another when it is FALSE.

=IF(A2>=50,"Pass","Fail")

IFS formula

IFS evaluates multiple conditions without nesting many IF functions.

=IFS(A2>=90,"Excellent",A2>=75,"Good",A2>=50,"Pass",TRUE,"Fail")
Tip: For complex logic, keep conditions in a clear order from highest priority to lowest.
